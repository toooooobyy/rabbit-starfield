# 玉兔号 · 星海航行 (Rabbit Starfield)

一个零依赖、单文件的粒子星海互动页面：真实银河系恒星坐标 + ASCII 字符战舰粒子。

**在线体验**：[GitHub Pages 演示](https://toooooobyy.github.io/rabbit-starfield/)

## 功能

- **真实银河系星海**：基于 HYG Database v4.1（约 12 万颗恒星，精选渲染），恒星位置、星等、色指数均来自真实星表
- **48 个精选目的地**：天狼星、织女星、天津四、南门二…… 点击星标即可自动航行抵达（中英文名称 + 真实距离）
- **曲速航行**：0-10 档速度滑杆，速度越快星海拖尾越长；自动瞄准 + 自动减速停靠；**调到 0 档随时暂停悬停**，状态栏实时显示递减的剩余距离与预计秒数
- **手动驾驶**（v2.2）：PC 端方向键转向 + 鼠标滚轮推进，滚轮下拉越过 0 档即切换倒退（星海拖尾反向、多普勒蓝红移对调、速度读数显示"倒退"）；移动端双指捏合张开前进 / 收拢倒退；抵达后引擎自动熄火不残留推力
- **恒星介绍随手查**（v2.2）：目的地列表每颗恒星带 ℹ 按钮，点击立即查看物理档案；星图中长按（550ms）或右键星标同样弹出信息卡，无需航行抵达
- **相对论效应**：高速航行时航向方向的恒星蓝移、后方红移，前方星光因"相对论聚光效应"增亮放大
- **抵达信息卡**：抵达目的地弹出该恒星物理档案（光谱类型、质量、半径、表面温度、科普简介），48 颗恒星均有真实数据
- **引擎音效**（可选）：Web Audio 合成的引擎轰鸣随速度变化，抵达时播放提示音，默认关闭
- **后视图重型战舰**：参考工业军事风格设计（宽扁舰体 + 平直宽翼 + 切角网格翼尖阵列 + 品字形三主发 + 翼根双辅助喷口 + 阶梯舰桥与天线），支持 7 种 ASCII/全角字符粒子
- **五喷口发动机喷焰**：静止时喷口仅存待机辉光，曲速加速时 3 主发 + 2 辅发全部喷射亮白→黄→橙红渐变火焰，喷焰长度随速度增长，高速时伴随机体高频微振
- **银河尘埃带**：程序化生成的银河盘面尘埃，增强空间纵深
- **抵达特效**：接近恒星时星体按真实亮度放大，平滑日冕光晕 + 白热核心
- **移动端适配**：竖屏抽屉式面板、安全区适配、飞船居中显示（正确处理高 dpr 屏幕）

## 操作

| 操作 | 效果 |
|------|------|
| 拖动 | 旋转视角 |
| 点击星标 ◇ | 选择目的地 |
| 方向键 | 手动转向（← → 偏航，↑ ↓ 俯仰） |
| 滚轮 / 顶部滑杆 | 推进 / 减速，滚轮下拉越过 0 档 = 倒退（移动端双指捏合同理） |
| 长按 / 右键星标 | 查看恒星介绍卡 |
| 目的地列表 ℹ | 查看恒星介绍卡 |
| `S` | 切换字符粒子 / 实心粒子 |
| `ESC` | 中止航行 |

## 技术说明

- 单文件 `index.html`（约 191 KB），无任何外部依赖，浏览器直接打开
- 恒星坐标以 Int16 定点压缩内嵌（10 字节/星），运行时软件光栅化渲染
- 战舰粒子静态缓存于离屏 Canvas（仅字符模式切换/窗口变化时重绘），喷焰为加法混合层
- 参数自动记忆（localStorage），音效默认关闭需手动开启

## 数据来源
