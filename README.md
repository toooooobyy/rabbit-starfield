# 玉兔号 · 星海航行 (Rabbit Starfield)

一个零依赖、单文件的粒子星海互动页面：真实银河系恒星坐标 + ASCII 字符玉兔粒子。

**在线体验**：[GitHub Pages 演示](https://toooooobyy.github.io/rabbit-starfield/)

## 功能

- **真实银河系星海**：基于 HYG Database v4.1（约 12 万颗恒星，精选渲染），恒星位置、星等、色指数均来自真实星表
- **48 个精选目的地**：天狼星、织女星、天津四、南门二…… 点击星标即可自动航行抵达（中英文名称 + 真实距离）
- **曲速航行**：0-10 档速度滑杆，速度越快星海拖尾越长，呈现加速冲刺效果；自动瞄准 + 自动减速停靠
- **后视图重型战舰**：参考工业军事风格设计，粒子构成的后视战舰（宽扁舰体 + 平直宽翼 + 切角网格翼尖阵列 + 品字形三主发 + 翼根双辅助喷口 + 阶梯舰桥与天线），桌面端鼠标划过粒子散开、移开后回弹恢复（触屏设备拖动仅旋转视角，不吹散飞船）；支持 7 种 ASCII/全角字符粒子
- **五喷口发动机喷焰**：静止时喷口仅存待机辉光，曲速加速时 3 主发 + 2 辅发全部喷射亮白→黄→橙红渐变火焰，主发喷焰长于辅发，喷焰长度随速度增长，高速时伴随机体高频微振
- **银河尘埃带**：程序化生成的银河盘面尘埃，增强空间纵深
- **抵达特效**：接近恒星时星体按真实亮度放大，平滑日冕光晕 + 白热核心

## 操作

| 操作 | 效果 |
|------|------|
| 拖动 | 旋转视角 |
| 点击星标 ◇ | 选择目的地 |
| 滚轮 / 顶部滑杆 | 调节曲速档位 |
| `S` | 切换字符粒子 / 实心粒子 |
| `ESC` | 中止航行 |

## 技术说明

- 单文件 `index.html`（约 178 KB），无任何外部依赖，浏览器直接打开
- 恒星坐标以 Int16 定点压缩内嵌（10 字节/星），运行时软件光栅化渲染
- 飞船粒子与发动机喷焰分别运行在离屏 Canvas 与加法混合层，与星海合成
- 参数自动记忆（localStorage）
